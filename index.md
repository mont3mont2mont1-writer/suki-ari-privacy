# Privacy Policy

Last updated: 2026-10-18

This policy applies to the Chrome extension "Cross Pixels:FLAG RUNNER" (the "Extension"), developed by MONT³.

## Information we collect

When "Send usage stats" is on (the default), the Extension sends the following to Google Analytics 4:

| Item                | Details                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------ |
| Anonymous client ID | A random ID generated by the Extension. It is not linked to your name, email address or Google account |
| Session ID          | The time the side panel was opened, used to group events                                               |
| Game start          | CPU level, and whether you or the CPU moved first                                                      |
| Game end            | CPU level, result (win, lose or resign), number of turns, and play time                                |
| Support link click  | Where the Ko-fi link was clicked (title screen or result screen)                                       |

We do not collect your name, email address, account information, browsing history, or the content of the pages you visit.

As with any communication over the internet, Google receives your IP address and browser information when this data is sent. Google handles this information under the [Google Privacy Policy](https://policies.google.com/privacy).

## How we use the information

We use it only to understand how many people play and to improve the game, for example to adjust the CPU levels. We do not use it for advertising, we do not sell it, and we do not share it with anyone other than Google, which processes it for us.

Collected data is kept in Google Analytics for 2 months.

## Data stored on your device

The Extension saves your settings, a game in progress, and the anonymous client ID in your browser (`chrome.storage.local`). This data stays on your device and is deleted when you remove the Extension.

## How to opt out

Turn off "Send usage stats" in Settings on the title screen. Nothing is sent from then on. Removing the Extension also deletes the anonymous client ID.

## External links

The support link opens Ko-fi in a new tab. Ko-fi's own privacy policy applies there.

## Changes to this policy

If we change this policy, we will update this page and the "Last updated" date.

## Contact

Please use the contact email address shown on the Extension's Chrome Web Store page.

# プライバシーポリシー

最終更新日: 2026-10-18

このポリシーは、MONT³ が開発した Chrome 拡張機能「Cross Pixels:FLAG RUNNER」（以下「本拡張機能」）に適用します。

## 取得する情報

設定の「利用統計の送信」がオン（初期設定）のとき、本拡張機能は次の情報を Google アナリティクス 4 に送ります。

| 項目                  | 内容                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------- |
| 匿名のクライアント ID | 本拡張機能が作るランダムな ID。氏名、メールアドレス、Google アカウントとは結び付きません |
| セッション ID         | サイドパネルを開いた時刻。イベントをまとめるために使います                               |
| 対戦の開始            | CPU の難易度、先手（あなたか CPU か）                                                    |
| 対戦の終了            | CPU の難易度、結果（勝ち・負け・降参）、手番数、プレイ時間                               |
| 応援リンクのクリック  | Ko-fi のリンクをクリックした場所（タイトル画面か結果画面か）                             |

氏名、メールアドレス、アカウントの情報、閲覧履歴、閲覧中のページの内容は取得しません。

インターネットの通信の性質上、これらを送るときに、Google は IP アドレスとブラウザの情報を受け取ります。これらは [Google のプライバシーポリシー](https://policies.google.com/privacy?hl=ja) に従って扱われます。

## 利用の目的

遊ばれている回数を知り、ゲームを改善する（CPU の難易度の調整など）ためだけに使います。広告には使わず、販売せず、処理を委ねる Google 以外には提供しません。

取得したデータは、Google アナリティクスに2か月保存します。

## 端末に保存する情報

本拡張機能は、設定、進行中のゲーム、匿名のクライアント ID を、ブラウザの中（`chrome.storage.local`）に保存します。これらは端末の外には出ず、本拡張機能を削除すると消えます。

## 送信を止める方法

タイトル画面の「設定」で「利用統計の送信」をオフにしてください。それ以降は何も送りません。本拡張機能を削除すると、匿名のクライアント ID も消えます。

## 外部のリンク

応援リンクは、Ko-fi を新しいタブで開きます。Ko-fi のページでは、Ko-fi のプライバシーポリシーが適用されます。

## ポリシーの変更

このポリシーを変更するときは、このページと「最終更新日」を更新します。

## お問い合わせ

本拡張機能の Chrome Web Store のページに記載の、連絡先メールアドレスにお問い合わせください。
